# Automatrix

![Automatrix Banner](https://raw.githubusercontent.com/harshasiddartha/automatrix/main/public/hero-dash.png)

A modern, high-performance web application built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**. Designed with clean UI components, light/dark mode support, and smooth interactions.

---

## ✨ Key Features

- **⚡ Next.js App Router**: Optimized server and client-side rendering architecture.
- **🎨 Tailwind CSS & Modern UI**: Sleek layout, custom component library, and fluid styling.
- **🌗 Dark / Light Mode**: Built-in theme toggling for seamless user experience.
- **🔒 Type-Safe Development**: Full TypeScript integration for strict static typing and reliability.
- **📱 Fully Responsive**: Tailored layout across desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org) (React)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Fonts:** Geist (via `next/font`)
- **Deployment:** Vercel
